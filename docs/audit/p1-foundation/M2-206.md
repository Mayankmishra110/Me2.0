# M2-206 — media-tools: Kokoro TTS and faster-whisper STT

## What was built
A uv Python project in `media-tools/` with one console script, `mediatools`, that has two subcommands following the ARCHITECTURE §2 child-process contract: `--in input.json --out output.json`, exit 0 on success, and on failure exit 1 with `error: …` on stderr. `tts` runs Kokoro-82M: `lang` en or hi maps to the Kokoro `a` or `h` voices, and it writes a 24 kHz wav plus word timings. English timings come from Kokoro tokens. Hindi falls back to proportional timings. `stt` runs faster-whisper on the CPU with `int8` and a `model_size` from the input, and returns segments with nested word timings. `MEDIATOOLS_OFFLINE=1` sets `HF_HUB_OFFLINE` and `TRANSFORMERS_OFFLINE` so no hub calls are made after the models are downloaded. The ticket is phase 2 in `tickets/`, but it has no dependencies and was built and merged during P1 (SPEC §2 "can start immediately").

Deviations from ARCHITECTURE / SPEC / DESIGN:
- CLAUDE.md says "one CLI per tool". The build is one `mediatools` CLI with `tts` and `stt` subcommands. This matches the ticket's own commands (`uv run mediatools tts|stt`) and ARCHITECTURE §9 (`mediatools/{tts,stt}.py`), so it is acceptable, but noted.
- "No network at runtime" holds only when `MEDIATOOLS_OFFLINE=1` is set. Without it, the Hugging Face hub may still contact the network even with cached models. The Go wrapper (`internal/media`, M2-209) must always set it after first download.
- Hindi word timings are proportional, not measured. This is recorded as an open question in the ticket.

## Known gaps and follow-ups
1. **The plain `uv run ruff check .` / `uv run pytest -q` fail on a fresh checkout.** `pytest` and `ruff` are under `[project.optional-dependencies] dev`, so `uv run` does not install them. This is the form used by the pre-commit hook, the PR template and the phase checks. The README says to run `uv sync --extra dev` first, which works around it, but a new worktree's first commit touching `media-tools/` fails the hook. Fix: move them to `[dependency-groups] dev` (PEP 735), which `uv run` installs by default, then re-lock. This belongs to ai, in a small follow-up ticket.
2. The Go caller must set `MEDIATOOLS_OFFLINE=1`, register the job as the `heavy` resource class (CLAUDE.md, 16 GB rule) and use a timeout. This is M2-209 / `internal/media`.
3. `out_wav` and `audio_path` accept any path. The daemon should pass paths under `data/media/work/<job-id>/` only (ARCHITECTURE §2).
4. HI word timings are proportional. Captions may drift, and a force-align with STT could fix it later. This is an open question for Mayank in the ticket.
5. The default voices are `af_heart` and `hf_alpha` until the channel brand kits set `voice_id` (DESIGN §3 still says TBD).
6. No dependency vulnerability audit was run (`pip-audit` is not installed, as SEC noted). torch and the model stack are large installs.
