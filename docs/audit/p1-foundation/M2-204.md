# M2-204 — Script writer (native EN and HI)

## What was built
`internal/content/formats/` is the format engine (CONTENT_STRATEGY §3 catalog + G6 variety picker).
`internal/content/script.go` is the Script stage: pick format → LLM Completer (`llm.TaskScript` + JSON
schema) → write `script.json` with long and short variants (hook, beats with visual cues, CTA, title,
description, tags ≤15, thumbnail text ≤4 words). Hindi uses an embedded Devanagari prompt with §4 craft
rules; redo notes from approvals are injected into the user prompt and stored on the doc.
