# M2-503 — Builder auditor: parallel audit against architecture/design

## What was built
`internal/builder/auditor.go` implements `builder.audit`: on `subphase.done` it opens a separate
detached worktree (`…/<branch>-audit`), builds a prompt from the subphase diff + plan ACs +
ARCHITECTURE/DESIGN, runs `claude -p` with `config.builder.auditor_model` (reusing M2-502's Claude
runner + disallowed tools), optionally best-effort Playwright screenshots, writes `audit/N.M.md`
(verdict defaults to **fail** if unparseable), and lands only test files + `audit/*.md` via CAS
`update-ref` onto the shared build branch. Never touches `main`.

## Spec audit
| Requirement | Where | Proof |
|---|---|---|
| Disabled / repos allowlist | `Auditor.Run` | `TestAuditorDisabledNoOp`, `TestAuditorRepoNotListed` |
| Triggered by `subphase.done` | `Auditor.Subscribe` | `TestAuditorSubscribeTriggeredBySubphaseDone` |
| Separate audit worktree | `ensureAuditWorktree` | path `…-audit`; never-main tests |
| Commits only tests + audit/*.md | `commitAuditWorktree` | `TestAuditorCommitsOnlyTestsAndAudit` |
| Writes audit file + lands on branch | `fastForwardBranch` | `TestAuditorWritesAuditFileAndLandsOnBranch` |
| Never touches main | shared `GitRunner` | `TestAuditorNeverTouchesMain` |
| Timeout / usage-limit shared shape | outcomes | `TestAuditorTimeoutAndUsageLimitOutcomes` |
| Verdict fail-default | `parseAuditVerdict` | `TestParseAuditVerdict` |

Deviations: audit worktree uses `--detach` + CAS `update-ref` because git forbids two checkouts of the
same branch (documented in ticket Notes). Non-FF landing returns retryable error (D25: landing
worktree owns retry; Gate never force-lands).
