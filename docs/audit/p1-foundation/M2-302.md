# M2-302 — Facebook Page publisher

## What was built
`internal/publish/facebook.go` implements SPEC §3 `Publisher` for Facebook Page Reels via Meta Graph
`video_reels` (start → rupload `file_url` → finish). Page-scoped token via injected `TokenSourceFor`,
`content.RequireApproved` before any Graph call, idempotency on `publications.idempotency_key`, daily
cap ≤3 fail-closed (`ErrDailyCapExceeded`), auth failures as `ErrReauthNeeded`, R2 `PresignGET` for
hosted upload URL, and caption AI/paid disclosure lines. Error bodies are redacted before parse/store
(`UploadHosted` mirrors `fbDoJSON`).
