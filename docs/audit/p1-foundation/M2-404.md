# M2-404 — Medium import-story link prep

## What was built
`internal/blog/medium.go` prepares Medium's historical "Import a story" link from the live
Mayankbuilt `publications.url` and delivers it to Mayank via Telegram. Nothing is published
to Medium by the daemon (CONTEXT D19). Tracking uses `content_items.stage=medium_link_sent`
plus an `events` row — never a fabricated Medium `publications` row.
