# M2-502 — Builder implementer: worktree + headless Opus, never main

## What was built
`internal/builder/implementer.go` implements `builder.implement`: for one approved subphase it creates
or reuses a git worktree under `data/worktrees/<repo>/<branch>`, runs `claude -p` headless (model from
`config.builder.implementer_model`) with the plan on stdin and a hard `run_timeout`, commits as
`N.M: <summary>`, and emits `subphase.done`. Disabled / repos-not-listed are clean no-ops. **Never
touches `main`** — fixed-argv git gate, Claude `--disallowed-tools`, post-run main-ref assert with
`restoreMainRef` on drift.
