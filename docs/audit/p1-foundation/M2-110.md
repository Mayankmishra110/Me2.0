# M2-110 — DPAPI token vault and OAuth helper

## What was built
`internal/secrets` stores OAuth tokens as DPAPI-protected blobs in `oauth_tokens`, with automatic
refresh via `golang.org/x/oauth2` that re-persists rotated tokens. `mayank2 auth <platform> <account>`
runs a loopback OAuth redirect on `127.0.0.1` (random port), uses PKCE where supported, and never
prints access/refresh tokens or auth codes.

- `internal/secrets/protect_windows.go` / `protect_other.go` / `protect.go` — DPAPI Protect/Unprotect.

## Config and keys
Uses existing `.env.example` OAuth client pairs (`GOOGLE_*`, `META_*`, `X_*`, `PINTEREST_*`,
`LINKEDIN_*`). Missing client id/secret → `OAuthConfig` error (auth CLI fails closed). No new schema;
`oauth_tokens` already in `001_init`. Tokens never logged.
