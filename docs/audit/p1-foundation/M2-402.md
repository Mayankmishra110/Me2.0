# M2-402 — Repurpose blog post to LinkedIn

## What was built
`internal/blog/repurpose_linkedin.go` rewrites a live Mayankbuilt post into a LinkedIn-native
draft via `llm.TaskBlog` (originality checks + approval.request for `linkedin`).
`internal/publish/linkedin.go` implements `Publisher` with `RequireApproved`, idempotent
`publications` lookup, ≤1/day fail-closed cap, DPAPI tokens, and official Posts API
(`POST /rest/posts`) plus OIDC WhoAmI for the member URN.

feed/update URN pattern; ApprovalService redo routing for blog kinds remains outside `touches`.
