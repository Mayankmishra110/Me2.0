# M2-403 — Repurpose blog post to X (personal account)

## What was built
`internal/blog/repurpose_x.go` turns a live Mayankbuilt post into an X thread via `llm.TaskBlog`
(normalize / word-boundary length / copy-paste reject), then opens `approval.request` for
`platform=x_personal`. `internal/publish/x_personal.go` implements `Publisher` with
`RequireApproved`, reply-chained `POST /2/tweets`, partial-thread recovery, ≤3/day fail-closed
cap, and hard personal↔business credential isolation (`SecretsPlatform="x"`,
`DefaultAccountRef="x-personal"`, symmetric `looksPersonalXAccount`).

## Spec audit
| Requirement | Where | Proof |
|---|---|---|
| TaskBlog → thread, not copy-paste | `XRepurposer.repurpose`, `normalizeThread` | `TestXRepurposer_*`, `TestLooksCopyPasted` |
| approval.request blog / x_personal | `XRepurposer.Start`/`Redo` | `TestXRepurposer_StartHappyPath`, `TestXRepurposer_Redo` |
| Platform `x_personal` distinct from business `x` | `PlatformXPersonal` | platform + idempotency tests |
| Credential isolation + refuse non-personal | `SecretsPlatform`, `looksPersonalXAccount` | `TestXPersonal_CredentialIsolation*`, `TestXPersonal_RefusesNonPersonalAccount` |
| RequireApproved before API | `XPersonal.Publish` | `TestXPersonal_RequiresApproval` |
| Reply-chain + partial resume, no double-cap | `Publish`, `reserveDailyCap` | `TestXPersonal_PublishHappyPath`, `PartialThreadRecovery`, `Idempotent` |
| Cap ≤3 fail-closed | `reserveDailyCap` | `TestXPersonal_CapExceeded` |
| Token redact on HTTP errors | `HTTPXPersonalAPI`, `redact` | `TestXPersonal_HTTPAPI_ErrorRedactsBody` |

Deviations: redo path owned inside repurposer (ApprovalService redo hardcodes `script.write`);
thread encoded in `PublishRequest.Description` JSON; platform-qualified job type constants without
`queue.Register` — all documented in ticket Notes.
