# M2-202 — Niche Scout

## What was built
`internal/content/scout.go` gathers daily topic candidates per channel from the YouTube Data API
(`search.list` + `videos.list`, quota-budgeted), configured RSS feeds, and an optional Trends endpoint
(D24 skip-clean when `TrendsBaseURL` is unset). Candidates are scored
`demand × freshness × fit × (1 − competition)`, with week-4+ analytics blend and ~20% exploration slots;
survivors are deduped against recent `topics` and inserted. Manual topics get a configurable boost.
API key comes from `YOUTUBE_API_KEY`; transport `*url.Error` URLs are stripped so the key never leaks in errors.
