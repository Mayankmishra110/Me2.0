# M2-207 — Stock visuals with license records

## What was built
`internal/media.Stock` searches Pexels then Pixabay for beat-matched video clips, filters by orientation and
minimum duration, skips a clip already used on the same channel within 30 days, downloads over HTTPS into the
caller's job folder with a size cap and timeout, and writes a `.license.json` sidecar next to every clip. No
asset is ever returned without a complete license record (D17, COMPLIANCE §2/F1).

**D24 (run with only the keys you have):** `NewStockFromEnv` enables a source only when its API key is set
and non-blank; with neither key set it returns a typed, `errors.Is`-matchable "not configured" error instead
of panicking or silently doing nothing.
