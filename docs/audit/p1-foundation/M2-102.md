# M2-102 — SQLite open, embedded migrations, initial schema

## What was built
`internal/db` opens SQLite in WAL mode with the required pragmas and applies embedded, append-only
migrations. `migrations/001_init.sql` creates every table from ARCHITECTURE §4 plus the required indexes.
`mayank2 migrate` is idempotent: it applies pending versions once and reports "already up to date" on repeat.
