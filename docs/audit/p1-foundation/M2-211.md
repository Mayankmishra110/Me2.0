# M2-211 — YouTube uploader for 4 channels

## What was built
`internal/publish/youtube.go` implements the SPEC §3 `Publisher` for YouTube Data API v3:
per-account OAuth token source, resumable upload, thumbnail, captions, optional playlist,
idempotency on `publications.idempotency_key`, daily quota reservation in `quotas`, and
compliance metadata (`selfDeclaredMadeForKids=false`, `containsSyntheticMedia`,
`containsPaidProductPlacement`). Always calls `content.RequireApproved` before any API call.
