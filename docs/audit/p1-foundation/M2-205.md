# M2-205 — Compliance script gates G1–G7

## What was built
`internal/compliance/` implements the script half of the Compliance & Originality Engine (COMPLIANCE §3
G1–G7). `Engine.Handle` / `JobScriptCompliance` (`ResourceHeavy`) runs gates, saves a §5-shaped report on
the content item, stores shingle/embedding fingerprints, and on failure enqueues `script.write` rewrite
(max 2) then dead-letters. G2 fails closed when priors exist without a usable embedding; rewrite payload
keeps compliance-owned keys after merging `ScriptWrite`.
