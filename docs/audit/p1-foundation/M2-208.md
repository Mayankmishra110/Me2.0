# M2-208 — Remotion compositions

## What was built
`remotion/` scaffolded (Vite + React + Remotion + TypeScript strict). Three format compositions
(`explained_60s`, `myth_vs_fact`, `top_n`), each registered in both orientations (16:9 landscape, 9:16
portrait) plus a still `thumbnail` composition (1280×720). Compositions are pure functions of props
(`BrandKit`, `Beat[]`, captions/word timings, audio, orientation) — no network or fetch at render time.

## Spec audit
| Requirement | Where in code | Proof |
|---|---|---|
| Props: brand kit, beats (text/clip/duration), voice file, word timings, orientation | `src/types.ts` | used by all 3 compositions + `samples/*.json` |
| Captions per `caption_style`; safe zones per DESIGN §3; thumbnail still | `CaptionsLayer` (word-highlight/karaoke/block), `captionSafeBox` | unit tests; `thumbnail` composition renders 1280×720 |
| CLI render with props JSON; sample of each format × orientation | `scripts/render-samples.ts`, `scripts/render-fixtures.ts` | `npm run render` → 6 mp4s + thumbnail.png in `out/` (gitignored); stills committed under `fixtures/` |

Deviations: Remotion composition IDs cannot contain `_`, so IDs use hyphens
(`explained-60s-portrait`, `myth-vs-fact-landscape`, `top-n-fixture`, …) while folder/format names keep the
ticket's underscore spelling. Cosmetic only, noted in the ticket.
