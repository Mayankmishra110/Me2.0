# M2-603 — Agency lead list + proposal drafts

## What was built
`internal/agency` tracks agency leads (`agency_leads`) and drafts outreach/proposal text
(`agency_proposals`) via `llm.TaskScript` (free-tier chain — never Claude). Every draft goes
through `approval.request` with kind `agency_proposal` before it is considered ready; approved
drafts sit for manual send — no email/DM/send clients are wired (PRD §5). Migration
`002_agency_leads.sql` is append-only; ARCHITECTURE §4 documents the new tables.
