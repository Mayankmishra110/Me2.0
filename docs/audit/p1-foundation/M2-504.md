# M2-504 — Builder phase gate: pass/fail-retry decision, timeout, limit pause

## What was built
`internal/builder/gate.go` implements `builder.gate`: reads `audit/N.M.md` via `git show
<branch>:<path>` (no worktree of its own), pass → gated on `builds`, fail → bounded retry
(`max_fix_attempts`) re-enqueuing implement with findings, exhausted → dead + alert, run_timeout
counts as a bounded failure, usage-limit pauses the repo+phase via a `settings` row and resumes via
`queue.RunAt`. Disabled / repos-not-listed are clean no-ops.
