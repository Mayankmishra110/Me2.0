# M2-209 — Render long, short, thumbnail, subtitles

## What was built
Queue handlers `voice.tts`, `render.long`, `render.short`, and `render.thumbnail` (all `ResourceHeavy`)
turn script + voice + clips into final media under storage. `internal/media/render.go` wraps media-tools
TTS, Remotion CLI, ffmpeg mux + `loudnorm=I=-14`, and pure-Go `.srt` from word timings via fixed argv +
timeouts. Payload paths are confined under `Layout.Root()`; assets get sha256, size, and `delete_after`.
