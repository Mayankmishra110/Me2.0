# M2-107 — Dashboard shell: Home, Approvals, Logs

## What was built
A mobile-first React 19 dashboard in `web/`, built with Vite, strict TypeScript, Tailwind v4, shadcn-style UI primitives, TanStack Query and React Router. It uses the DESIGN §1.3 color tokens, with dark mode as the default. The app shell has a desktop sidebar and bottom tabs at ≤ 640 px. The top bar shows the status pill with icon and label, the live SSE dot, the pending count, a Claude-limit badge and a Pause all switch. There are three screens: Home, Approvals (list and detail with player, compliance gates, destinations, sources, and Approve/Reject/Redo with a double-submit lock) and Logs. An MSW mock covers every SPEC §4 path until M2-106 serves the real API. An SSE client reconnects with exponential backoff and invalidates the matching queries.

## Known gaps and follow-ups
1. **Risk: MSW ships in the production bundle.** `main.tsx:prepare` starts the mock worker unless `VITE_USE_MSW === 'false'`, and `public/mockServiceWorker.js` is copied into `dist`. Once M2-106 embeds `web/dist`, the real dashboard would show mock data unless the build sets that flag. Recommend gating on `import.meta.env.DEV` (or making the flag opt-in) before or inside M2-106.
2. The mobile tab set differs from DESIGN §1.1 (Logs instead of Pipeline/Builder). Revisit when those screens land.
3. The status pill defaults to `degraded` while `/api/health` is loading (`TopBar.tsx`), so a brief false "Degraded" shows on first paint.
4. For 9:16 items the player box is narrowed, but the `<video>` keeps `aspect-video` (16:9) inside it, so vertical previews are letterboxed.
5. There are no tests for `sse.ts` reconnect and backoff, HomePage, LogsPage or the Pause all switch. The only tests cover the Approvals decision flow, which is what the ticket asked for.
6. `web/README.md` is still the Vite template boilerplate. Setup, the MSW flag and scripts should be documented.
7. Fonts load from Google Fonts at runtime. This is an offline or Tailscale-only dependency to consider: self-host them later if the dashboard should work without internet.
8. Inline title/description edit, a light theme toggle, and the Sheet/Tabs/Toast components from DESIGN §1.3 are not built yet.
