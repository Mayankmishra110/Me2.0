# M2-108 — Scheduler and daily summary

## What was built
`internal/scheduler/` wraps `robfig/cron/v3` with the configured timezone. Cron and startup catch-up only
**enqueue** jobs (`summary.daily`, `storage.cleanup`, plus placeholders `scout.topics` / `analytics.pull`);
handlers run the real work. Daily summary text follows DESIGN §2 (published counts, pending approvals,
failures, best performer, quota lines, disk free, Claude limit state) and is sent through an injectable
`Notifier` (Telegram wired from cmd). Missed fires while the laptop was off enqueue once on startup via
settings watermarks (`scheduler:last:<type>`). Storage cleanup loads due `assets`, calls `storage.Cleanup`,
and optionally R2 via `NewR2FromEnv` (D24 skip-clean).
