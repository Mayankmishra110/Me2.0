# M2-201 — Channel and format config

## What was built
`internal/content` loads and validates `config/channels/*.yaml` (language en/hi, known format IDs,
caption styles), upserts into the existing `channels` table with `warmup_started_at` on first insert,
and implements `CapsFor` ramp-up caps from COMPLIANCE §4. Reuses `config.LoadChannel` for base parse;
does not modify `internal/config` or channel YAML files (already present from M2-101).

2. **Week 4+ long/week** returns upper bound `4` (COMPLIANCE range 3–4).
3. **`status=paused` not special-cased** in CapsFor — scheduler concern.
4. **No CLI/job wiring** — library only; out of touches.
