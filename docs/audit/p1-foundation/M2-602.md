# M2-602 — Micro-SaaS idea → spec → Builder flow

## What was built
`internal/micro_saas` turns a manual product idea into ARCHITECTURE/SPEC drafts via
`llm.TaskBuilder` (Claude), requests approval (`kind=micro_saas_spec`), then on approve
writes those docs under an allowlisted `config.builder.repos[].path` and enqueues
`builder.plan`. Stages: `submitted → spec_drafted → approved → handed_to_builder`.
Reuses `content_items` (`format=micro_saas_idea`); no new migration. `RevenueNudge` only
reminds Mayank to POST `/api/revenue` — never fabricates a revenue row.

## Spec audit
| Requirement | Where | Proof |
|---|---|---|
| Submit + stage transitions | `Service.Submit` / stages | `TestSubmitDraftHandOffAndRefuseBadRepo` |
| Spec draft via TaskBuilder | `Service.Draft` + `LLM.Complete` | draft tests (fake Completer) |
| Approval before hand-off | `Approvals.Start` kind `micro_saas_spec` | submit/draft path |

| Disabled no-op | Enabled gate | `TestDisabledNoOp` |
