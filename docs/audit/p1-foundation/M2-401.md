# M2-401 — Blog draft to Mayankbuilt (canonical post)

## What was built
`internal/blog/draft.go` and `merge.go` implement SPEC §5 `blog.draft` / `blog.merge` for the
Mayankbuilt canonical MDX post (ARCHITECTURE §3.2, CONTEXT D19). Draft calls LLM task `"blog"`,
writes MDX on a `blog/<slug>` branch via fixed-argv git, and starts an approval. Merge
re-checks `content.RequireApproved`, fast-forwards `--ff-only` onto the configured base, and
records an idempotent `publications` row with `platform=mayankbuilt`. Tokens are redacted from
git errors; MDX `assets.path` is absolute for M2-402.
