# M2-203 — Research brief with sources

## What was built
`internal/content/research.go` builds a sourced research brief per topic for EN/HI scripts. It fetches
up to N web pages (robots.txt User-agent: * gate + readable-text extraction, 2 MiB / 30s caps) or a
video transcript via injectable `FetchTranscript` (notes only — COMPLIANCE §2 / D17). An LLM Completer
(`llm.TaskResearch`) produces `brief.json` (angle, facts[] each with ≥1 source URL, key numbers, open
questions, sources[]). Source texts land under `OutDir/sources/<sha16>.txt` for the G1 originality gate.
