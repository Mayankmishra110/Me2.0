# M2-105 — Telegram bot: allowlist, commands, approvals, PIN

## What was built
`internal/telegram` is a raw-HTTPS Telegram Bot API client (no SDK) with long-polling `getUpdates`,
offset stored in `settings`, and a hard allowlist on `from.id` + `chat.id`. Commands cover status /
today / queue / pause / resume / topic / blog / help; bulk `/pause` and `/resume` require a bcrypt PIN
gate. `approval.request` jobs send preview + Approve/Reject/Redo buttons with single-use nonces.
SEC follow-ups: token redaction in HTTP errors, preview paths confined under `data/`.
