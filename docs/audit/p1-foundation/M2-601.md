# M2-601 — Revenue tracking: manual + semi-automated entries, revenue API

## What was built
`internal/revenue` records every ads/affiliate/agency/saas/sponsor dollar into the existing `revenue`
table (`Record` / `List` with line + date filters). `GET/POST /api/revenue` replaces the M2-106 empty
stub (auth-gated, validation, `revenue.recorded` event). `Puller.Pull` idempotently upserts YouTube
`estimatedRevenue` (`line:"ads"`); Meta auto-pull is refused (manual entry only). Dashboard
`RevenuePage` shows totals-by-line, entries table, and an add form.
