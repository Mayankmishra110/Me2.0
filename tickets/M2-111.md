## Goal
One `llm.Complete(ctx, task, req)` call that picks the first available provider for the task.

## Acceptance criteria
- [ ] Providers: `ollama` (chat + embeddings), `openai_compat` (Groq, Cerebras, OpenRouter, Gemini), `claude_cli` (`claude -p --output-format json`, prompt via stdin).
- [ ] Routes from config; on 429/5xx/timeout, mark the provider unavailable until its window resets (tracked in `quotas`) and fall through the chain.
- [ ] Optional JSON-schema output with validation and one repair retry.
- [ ] Job results record provider + model (shown in the dashboard).
- [ ] Tests with `httptest` servers for fallthrough and quota handling.
