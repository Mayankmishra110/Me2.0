## Goal
One `llm.Complete(ctx, task, req)` call that picks the first available provider for the task.

## Acceptance criteria
- [x] Providers: `ollama` (chat + embeddings), `openai_compat` (Groq, Cerebras, OpenRouter, Gemini), `claude_cli` (`claude -p --output-format json`, prompt via stdin).
- [x] Routes from config; on 429/5xx/timeout, mark the provider unavailable until its window resets (tracked in `quotas`) and fall through the chain.
- [x] Optional JSON-schema output with validation and one repair retry.
- [x] Job results record provider + model (shown in the dashboard).
- [x] Tests with `httptest` servers for fallthrough and quota handling.
