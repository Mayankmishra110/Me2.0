## Review

QA: changes — 2026-09-28 — gofmt/vet/`go test -count=1 ./...` green (go1.27.0); scope OK; ACs covered by tests; blockers below.
1. `internal/content/render.go:93-97` — `retention()` uses `RetentionDays >= 0`, so a zero-value `Renderer` (unset field) writes `delete_after` = now instead of `defaultRetentionDays` (7). Tests always set `RetentionDays: 7`, so this is masked. Fix: treat unset/`0` as default (`if RetentionDays > 0 { … } else { return defaultRetentionDays }`) or use `*int`; add a unit test that omit/zero yields +7 days.

SEC: changes — 2026-09-28 — exec path is fixed-argv + timeout (good); media payload paths are not confined.
1. `internal/content/render.go:249,319-329,365,410` — `voice_path`, `beats[].clip_path`, and `focal_clip_path` go straight into `StagePublic` / `MuxAV` with no check they lie under `Layout.Root()` (`data/media`). Sec checklist + ARCHITECTURE §2 require paths confined to `data/`; a crafted/buggy job payload can copy host files (e.g. `.env`) into `remotion/public/jobs/<id>/`. Fix inside touches: Abs+Clean each path in `content/render.go` and refuse (permanent) unless under `r.Layout.Root()` (local prefix check OK — do not expand touches into `storage/`); add a test that an outside-root path fails closed.
