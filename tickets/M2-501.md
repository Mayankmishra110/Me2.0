## Goal
`builder.plan` job that reads a target repo's `ARCHITECTURE.md`, `SPEC.md`, `designs/` and its `tickets/*.md` (via the existing `internal/tickets` parser), and produces an ordered subphase plan (`plans/phase-N/N.M-<slug>.md` in the target repo, per ARCHITECTURE §3.3) with acceptance criteria per subphase, generated via `internal/llm.Complete(ctx, "builder", req)` (Claude, per D13/config's `llm.routes.builder`). Once written, the plan goes through `approval.request` exactly like every other publish/build path (D5) — Mayank approves the plan once before any subphase starts (PRD §4 M6, ARCHITECTURE §3.3).
