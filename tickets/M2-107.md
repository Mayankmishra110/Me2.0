### Mock JSON shapes (SPEC §4 paths only; full schemas land with M2-106)
- `GET /api/health` → `{ ok, version, paused, status, claudeUsageLimitHit }`
- `GET /api/agents` → `{ agents: [{ id, name, state, currentJob, lastSuccess, nextRun }] }`
- `GET /api/jobs` → `{ jobs: [{ id, type, status, channel, error, updatedAt }] }`
- `GET /api/approvals` → `{ approvals: [{ id, title, channel, format, status, createdAt }] }`
- `GET /api/approvals/:id` → detail + `compliance.gates`, `sources`, `destinations`, media URLs
- `POST /api/approvals/:id/decision` → body `{ decision, note?, edits? }` → `{ ok, id, decision, decidedAt }`
- `POST /api/pause|resume` → `{ scope }` → `{ ok, paused, scope }`
- SSE `data:` frames → `{ kind, at, payload }`
