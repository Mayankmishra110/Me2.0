## Goal
OAuth tokens stored encrypted; a CLI to sign in to each platform account.

## Acceptance criteria
- [ ] `secrets.Protect/Unprotect` via `CryptProtectData` (`golang.org/x/sys/windows`); non-Windows builds return an error.
- [ ] `oauth_tokens` read/write with automatic refresh through `golang.org/x/oauth2`.
- [ ] `mayank2 auth <platform> <account>`: loopback redirect on 127.0.0.1 (random port), PKCE where supported, stores the token, never prints it.
- [ ] Tests for encryption round-trip (Windows only) and refresh logic with a fake token server.
