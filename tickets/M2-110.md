## Notes

### Plan (crew-be-3, 2026-09-28)
- `internal/secrets/protect_windows.go` (+ `protect_other.go`): `Protect`/`Unprotect` via
  `windows.CryptProtectData` / `CryptUnprotectData` (`CRYPTPROTECT_UI_FORBIDDEN`); copy out bytes then
  `LocalFree`. Non-Windows build returns a clear error. Never log plaintext/ciphertext.
- `internal/secrets/store.go`: `Store` over `oauth_tokens` — JSON-encode `oauth2.Token`, DPAPI-protect into
  `encrypted_blob`, mirror `expires_at`. `Get`/`Put`; `TokenSource` wraps `oauth2.Config.TokenSource` and
  persists refreshed tokens. Injectable crypter in tests so refresh works without DPAPI.
- `internal/secrets/platform.go`: registry for `youtube|google`, `meta|facebook|instagram`, `x|twitter`,
  `pinterest`, `linkedin` → env client id/secret pairs (already in `.env.example`), endpoints, default
  scopes. PKCE (S256) for google/youtube, x, pinterest, linkedin; Meta keeps confidential-client secret
  (no PKCE).
- `cmd/mayank2/auth.go`: `mayank2 auth <platform> <account>` — listen `127.0.0.1:0`, build redirect,
  print auth URL (best-effort open browser), validate `state`, exchange (+ PKCE verifier), `Store.Put`,
  print success only (never token/code). Flags: `-config`/`-env`/`-db` like migrate.
- Tests: Windows-only Protect/Unprotect round-trip; Store Put/Get + refresh against `httptest` token
  server with passthrough crypter; auth flag/parse + platform lookup unit tests.
- Risks: loopback-only redirect; state CSRF; never print tokens; `needs-sec: yes`.
- Dep: `golang.org/x/oauth2` (direct). No schema change (`oauth_tokens` already in 001_init).
