## Goal
`mayank2` binary with subcommands and a config loader for the full schema, plus `doctor` that reports whether this laptop is ready.

## Acceptance criteria
- [ ] Go 1.24+ in `go.mod`; `cmd/mayank2` with subcommands `run`, `status`, `doctor`, `migrate`, `set-pin`, `auth` (stubs OK except `doctor`).
- [ ] `internal/config` loads `config/config.yaml` (schema = `config/config.example.yaml`), `config/channels/*.yaml`, and `.env`; relative paths resolve against the config file; clear errors on invalid values. Replaces the early Builder-only config.
- [ ] `doctor` checks and prints ✅/❌: ffmpeg, node, uv/python, ollama reachable + models pulled, claude CLI, git, disk free ≥ 100 GB, RAM, each `.env` key present (value never printed), channel files valid.
- [ ] Table-driven tests for config loading and validation.
