## Goal
Phone control. The bot only talks to Mayank and handles approvals safely.

## Acceptance criteria
- [ ] Long-polling `getUpdates` with the offset stored in `settings`; raw HTTPS client, no SDK.
- [ ] Drops (and logs as an event) any update whose `from.id` or `chat.id` is not configured.
- [ ] Commands: `/status`, `/today`, `/queue`, `/pause`, `/resume` (PIN prompt, bcrypt check), `/topic`, `/blog`, `/help`.
- [ ] `approval.request` job sends a preview (video/photo/text) with buttons; callback `approve|reject|redo:<id>:<nonce>`; nonce single-use; message edited to show the decision; redo asks for a note.
- [ ] No command executes a shell or arbitrary code.
- [ ] Tests with an `httptest` fake Bot API: stranger ignored, double tap ignored, PIN required.

## Notes

**Plan (2026-09-28, crew-be):**
1. `internal/telegram`: raw HTTPS Bot API client (no SDK); long-poll `getUpdates` with offset in `settings` key `telegram:offset`.
2. Allowlist: require `from.id` **and** `chat.id` match env `TELEGRAM_USER_ID` / `TELEGRAM_CHAT_ID`; strangers → drop + insert `events` row (`telegram.ignored`); never log token/PIN.
3. Commands (text only, no shell/exec): `/status`, `/today`, `/queue`, `/pause`, `/resume` (PIN prompt → bcrypt vs `settings.pin_hash`), `/topic`, `/blog`, `/help`. Pause/resume via `queue.Pause*` / `Resume*` (`all`|`heavy`|`light`|`net`).
4. `approval.request` handler: send video/photo/text + Approve/Reject/Redo buttons; callback `approve|reject|redo:<id>:<nonce>`; single-use nonce (clear on decide); edit message; redo → ask note then store.
5. Emit events by writing `events` table directly (M2-104 not yet on this base); inject `*queue.Queue` for pause; `golang.org/x/crypto/bcrypt` for PIN (touches go.mod/sum).
6. Tests (`httptest` fake Bot API, no network): stranger ignored+event; double-tap ignored; PIN required for resume; happy-path allowlisted command + approve once.
7. **needs-sec: yes** — telegram allowlist, callback nonces, PIN/bcrypt.

Risks: `/status`/`/today` are best-effort over current schema (no agent cards yet); agent-name pause beyond resource classes sets `pause:agent:<name>` for later workers.
