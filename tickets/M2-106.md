## Goal
The REST + SSE API from SPEC §4, protected by token login, serving the embedded dashboard.

## Acceptance criteria
- [ ] Binds only to `127.0.0.1` and the Tailscale IP from config.
- [ ] `POST /api/login` with `DASHBOARD_TOKEN` → `HttpOnly; SameSite=Strict` session cookie; every other route requires it.
- [ ] All endpoints in SPEC §4 (return empty lists where the backing module is not built yet).
- [ ] Serves `web/dist` via `embed.FS` with SPA fallback.
- [ ] Tests for auth, the approvals decision flow, and the SSE stream.

## Notes

### Plan (be-2, 2026-09-28)

- Package `internal/httpapi/` only (touches). Wire against existing `internal/{config,db,events,queue}` without editing them.
- Files: `server.go` (Server + mux), `auth.go` (login + session cookie + middleware), `bind.go` (resolve `127.0.0.1` / `tailscale` listen addrs; reject anything else), `routes.go` (SPEC §4 stubs returning empty lists where modules missing), `approvals.go` (list/detail/decision against SQLite + emit `approval.decided`), `sse.go` (Subscribe + heartbeat per events/doc.go), `spa.go` (`embed.FS` of `dist/` + SPA fallback to `index.html`), `dist/index.html` placeholder (real `web/dist` copied in by `scripts/build.ps1` / M2-110 wiring — `go:embed` cannot escape the package dir).
- Auth: `POST /api/login` body `{token}` compared constant-time to SHA-256 of `DASHBOARD_TOKEN` (ARCHITECTURE §7 "stored as a hash"); issue opaque session id in `HttpOnly; SameSite=Strict; Path=/` cookie. Middleware requires cookie on every route except `GET /api/health`. Soft login rate-limit in-memory.
- Bind: `ResolveListen` expands `tailscale:PORT` via injectable Tailscale-IP lookup (real: `tailscale ip -4`); validates host is loopback or that resolved Tailscale IP only. `Listen` starts one `http.Server` per addr. Tests cover resolve/validate with no real network.
- Approvals decision: pending → approve|reject|redo; 409 if already decided; optional note/edits; Emit `approval.decided`. Resume checks bcrypt `settings.pin_hash` when present.
- Tests (httptest, table-driven, no network): auth cookie flags + 401 without session; approvals decision flow; SSE receives emitted event. Pause/health/empty endpoints covered lightly.
- needs-sec: yes (auth/session, bind surface, cookie flags).
